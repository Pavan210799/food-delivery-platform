# Marlow

A modern food delivery front end: restaurants, menus, customization, cart, coupons, checkout, order confirmation with a live status timeline, and order history.

## Stack

- React + Vite
- Tailwind CSS
- React Router
- Context API
- Framer Motion
- LocalStorage for cart and orders

## Run

```bash
npm install
npm run dev
```

## Coupons

- `WELCOME15` — 15% off food, from $25
- `MARLOW10` — $10 off food, from $40
- `FREESHIP` — free delivery, from $20

Checkout asks only for name, phone, and delivery address. Orders are stored in the browser and the status timeline advances over time.
